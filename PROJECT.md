# MovieFinder

A responsive movie search website built with HTML, CSS, and JavaScript. Movie data is fetched dynamically from the OMDb API.

## Live website
https://wonderful-seahorse-212883.netlify.app/

## Features
- Automatically displays Batman movie results on page load
- Search movies by title using the OMDb API
- Display movie posters, titles, years, and types
- Sort A–Z, Z–A, newest to oldest, and oldest to newest
- Load more results
- Loading spinner, empty state, and error messages
- Responsive layout for desktop and mobile

## How to use
Open `index.html` in a browser, or visit the deployed site. Search for a title such as Spider-Man and choose a sorting option.

## Technologies
HTML5, CSS3, vanilla JavaScript, Fetch API, OMDb API.

**Note:** The demo uses a free OMDb API key in client-side JavaScript. Client-side keys are visible to visitors; a production application should use a server-side proxy to protect secrets.
